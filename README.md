# loginAppAS
## Opis projektu

### Aplikacja przedstawiająca ekran rejestracji konta, przygotowana w Android Studio.
Elementy ekranu:
- Nagłówek „Rejestruj konto” z turkusowym tłem.
- Pole adresu e-mail.
- Dwa pola hasła z ukrywaniem wpisywanych znaków.
- Przycisk „ZATWIERDŹ”.
- Etykieta powitania.
---
## Technologie
- Java - plik MainActivity.java pozostawiony bez zmian.
- XML - układ ekranu oparty na pionowym LinearLayout.
- strings.xml - teksty widoczne dla użytkownika.
